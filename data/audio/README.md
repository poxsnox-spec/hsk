# 📁 Папка для аудиофайлов HSK 5

Положи сюда mp3-файлы из официального аудиокурса HSK 5 上.
Программа ищет их по структуре:

data/audio/unit1/lesson01/
    ├── textbook_1.mp3     ← учебник, текст (первое чтение)
    ├── textbook_2.mp3     ← учебник, текст (повторное чтение)
    ├── vocab.mp3          ← все 生词 урока подряд
    ├── workbook_01-1.mp3  ← рабочая тетрадь, 听力 часть 1
    └── workbook_01-2.mp3  ← рабочая тетрадь, 听力 часть 2

Если файлов нет — программа работает без ошибок,
кнопки 🔊 просто будут неактивны.
